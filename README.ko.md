# 비즈니스 모델 × 조직 아틀라스

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · **한국어** · [Español](README.es.md) · [Français](README.fr.md)

**비즈니스 모델의 선택**과 **조직 형태·힘·변화**를 연결하는 인터랙티브 아틀라스입니다. 헨리
민츠버그의 『Understanding Organizations...Finally!: Structure in Sevens』(Berrett-Koehler,
2023)를 해석한 필드 가이드이며, 원서를 대신하지 않습니다.

창업자, 운영자, 컨설턴트, 학생이 "이 조직은 왜 이렇게 움직이는가", "다른 모델에 맞추려면 무엇을
바꿔야 하는가"라는 더 나은 질문을 던지도록 돕습니다.

- **계정 없음, 백엔드 없음, 분석 없음.** 모든 계산은 브라우저 안에서 이루어집니다.
- **6개 언어.** English, 简体中文, 日本語, 한국어, Español, Français를 즉시 전환할 수 있습니다.
- **빌드 없음, 의존성 없음.** 순수 HTML, CSS, 네이티브 ES Modules만 사용합니다.

## 둘러보기

아틀라스는 10개 섹션으로 구성되며, 처음에는 「브리지」가 열립니다.

| 섹션 | 할 수 있는 일 |
| --- | --- |
| **01 브리지** | 고객·가치·경제·경계의 네 가지 모델 선택을 조합해 어떤 조직 형태로 기울는지, 어디서 긴장이 생기는지, 무엇으로 균형을 잡는지 확인합니다. |
| **02 캔버스** | 비즈니스 모델의 9개 블록을 조직 관점에서 차례로 살펴봅니다. |
| **03 패턴** | 언번들드, 롱테일, 멀티사이드, 무료, 오픈의 다섯 패턴을 탐구합니다. |
| **04 디자인** | 고객·가치·자원·재무 중 어디서 설계를 시작할지 고르고, 모델을 조직으로 연결합니다. |
| **05 사례** | 실제 기업 사례를 읽고 해당 브리지 시나리오로 바로 이동합니다. |
| **06 아틀라스** | 네 가지 기본 형태를 다이아몬드 지도에 배치하고 세 가지 보조 형태도 살펴봅니다. |
| **07 형태** | 일곱 형태의 조정 엔진, 권력 패턴, 적용 조건, 위험, 사례를 깊이 읽습니다. |
| **08 힘** | 일곱 가지 힘을 슬라이더로 조정하면 현재 기울는 형태와 이를 견제하는 힘을 보여 줍니다. |
| **09 변화** | 수명 주기 단계와 일반적인 전환 경로를 따라갑니다. |
| **10 소개** | 출처, 범위, 방법을 확인합니다. |

## 빠른 시작

정적 파일을 제공하기 위해 **Node.js 18+** 또는 **Python 3**만 있으면 됩니다. 설치나 빌드는 필요
없습니다.

```bash
# 권장: 의존성 없는 내장 Node 서버
npm start
```

```bash
# 대안: Python 정적 서버
python -m http.server 8765 --bind 127.0.0.1
```

<http://127.0.0.1:8765/> 를 엽니다. 서버를 멈추려면 `Ctrl+C`를 누릅니다.

**왜 로컬 서버가 필요한가요?** 앱은 네이티브 ES Modules를 사용합니다. 브라우저는 보안상
`file://` 페이지에서 모듈 불러오기를 차단하므로 `index.html`을 더블클릭하면 빈 페이지나 오류가
납니다. HTTP로 열면 코드를 바꾸지 않고도 정상 동작합니다.

8765 포트가 이미 사용 중이라면:

```bash
PORT=9000 npm start
```

Windows PowerShell에서는 `$env:PORT=9000; npm start`로 입력합니다.

## 동작 방식

모듈은 한 방향으로만 의존합니다.

```text
data  ->  i18n  ->  ui  ->  app.js
```

- **`js/data/`** 는 리프 모듈입니다. 일반 객체만 내보내고 아무것도 가져오지 않아 테스트, 비교,
  재사용이 쉽습니다.
- **`js/i18n/`** 이 현재 언어를 소유합니다. 번역 키는 마크업과 데이터에서 쓰는 영어 원문 그대로이므로
  영어용 조회 표가 필요 없고, 번역이 없으면 안전하게 영어로 대체됩니다.
- **`js/ui/`** 는 뷰마다 하나의 모듈입니다. 각 모듈이 상태를 소유하고 `renderXView()`와
  `initXView()`를 내보냅니다. 뷰 간 동작은 좁은 API를 통합니다. 예를 들어 다른 뷰는 브리지 상태를
  직접 바꾸지 않고 `applyBridgePreset()`을 호출합니다.
- **`js/app.js`** 는 구성 루트입니다. 모듈을 연결하고 정해진 순서로 렌더링하며, 언어 선택기와
  `#bridge`, `#atlas` 같은 딥 링크를 처리합니다.

구현 세부 사항:

- CSS는 원래 캐스케이드 순서로 불러옵니다. `responsive.css`와 `overrides.css`는 반드시 마지막에
  있어야 합니다.
- 유일하게 저장되는 값은 `localStorage`의 언어 설정(`organization-atlas-language`)입니다. 읽기와
  쓰기 실패도 처리합니다.
- 내비게이션은 `history.replaceState`를 사용하므로 탭 전환으로 브라우저 기록이 쌓이지 않습니다.
- 제목은 언어와 화면 너비에 맞춰 자연스럽게 줄바꿈되며 동작 줄이기 설정을 지원합니다.
- Google 검색 안내 사례, Canvas 블록 연결, 시나리오 비교, 두 조직 형태 비교를 제공합니다. 사례와 비교 상태는 현재 페이지 방문 중에만 유지됩니다.

## 자주 하는 작업

**문구나 도메인 데이터 바꾸기.** `js/data/`의 해당 파일이나 `index.html`의 텍스트를 편집합니다.
데이터는 일반 객체이므로 빌드 단계가 없습니다.

**번역 추가·수정.** 영어 원문(번역 키)을 찾아 `js/i18n/translations.js`의 해당 언어에 추가합니다.
소량 추가는 파일 끝의 `Object.assign(translations.<언어>.strings, { ... })` 방식을 그대로 쓰면
됩니다.

**언어 추가.** `js/i18n/languages.js`에 메타데이터를 추가하고, `translations.<언어>` 객체를 추가하거나
할당한 뒤, `index.html`의 `#language-select`에 `<option>`을 추가합니다.

**형태나 힘 추가.** 해당 데이터 모듈을 갱신하고 UI 컨트롤을 추가하며, 브리지와 모델 프로필 데이터도
확장합니다. 마지막으로 감사를 실행하세요. 파일 간 외래 키 일관성을 검사합니다.

## 품질 검사

```bash
npm run audit
```

감사는 의존성 없이 다음을 검증합니다.

- 모든 JavaScript 모듈이 구문 분석되고, 상대 경로만 가져오며, 의존 그래프에 순환이 없다.
- 페이지에는 외부 module 스크립트가 하나뿐이고, 인라인 스크립트·스타일·이벤트 핸들러·`style`
  속성이 없다.
- CSP가 기본 거부이며 `unsafe-inline`과 `unsafe-eval`을 포함하지 않는다.
- 스타일시트 순서가 올바르고 모든 CSS `url()` 대상과 WOFF2 폰트가 존재하며 유효하다.
- 요소 ID가 고유하고, 프래그먼트·로컬 링크·외부 HTTPS 링크가 안전하며, 외부 링크가
  `noopener noreferrer`를 사용한다.
- JavaScript가 참조하는 모든 DOM ID가 HTML에 존재한다.
- 데이터 외래 키가 일치한다: 형태, 프로필, 구조도, 힘, 프리셋, 브리지 그룹, 브리지 프리셋,
  긴장 규칙, 패턴, 단계, 경로, 캔버스 블록, 디자인 중심.
- 주요 텍스트 색상이 세 가지 배경 모두에서 WCAG AA 대비(4.5:1)를 충족한다.
- 6개 언어 README가 모두 존재한다.

## 안전과 개인정보

- 페이지는 **어떤 네트워크 요청도 하지 않으며** 백엔드, 분석, 쿠키, 폼, iframe, 사용자 콘텐츠
  수집이 없습니다.
- 저장되는 값은 `localStorage`의 언어 선택뿐입니다.
- 외부 사례·라이선스 링크는 사용자가 직접 클릭한 뒤에만 열리며 `rel="noopener noreferrer"`를
  사용합니다.
- 동적 HTML 템플릿은 번역 텍스트를 이스케이프합니다. 구조적 SVG 본문은 신뢰된 정적 소스
  데이터입니다.
- CSP는 원격 리소스와 모든 데이터 연결을 차단합니다. 공개 배포 시에는 웹 서버나 CDN에서 응답 헤더
  CSP와 `frame-ancestors 'none'`을 추가하세요.

## 폰트와 라이선스

**Inter**와 **Noto Sans SC / JP / KR**의 로컬 WOFF2 서브셋을 포함합니다. 모두 SIL Open Font
License 1.1로 제공됩니다. 전체 저작자 표시와 라이선스 본문:

- [`assets/fonts/FONT-LICENSES.txt`](assets/fonts/FONT-LICENSES.txt)

타사 서버에서 폰트를 불러오지 않습니다.
